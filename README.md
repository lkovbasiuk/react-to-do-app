# React To-Do App

React To-Do App is a task management web application that helps users organize daily activities, track tasks, and improve productivity.
The project provides a clean and intuitive interface for creating, editing, completing, and deleting tasks with responsive user experience.

Experience the live website [here](https://lkovbasiuk.github.io/react-to-do-app/)

## Technologies Used

- React
- TypeScript
- SCSS / CSS Modules
- JavaScript
- React Hooks
- Responsive Web Design
- HTML5
- Git & GitHub

## Getting Started

Follow these steps to run the project locally.

### Clone the repository

```bash
git clone https://github.com/your-username/project-name.git
cd project-name
```

### Install dependencies

```bash
npm install
# or
yarn install
```

### Run the project locally

```bash
npm start
# or
yarn start
```

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed

- Filter tasks by status
- Responsive design for mobile and desktop
